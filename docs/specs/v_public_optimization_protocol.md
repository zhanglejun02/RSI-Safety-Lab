# v 公开优化目标与后续机制实验协议

版本：`public-v-objective-preflight-v1`。日期：2026-11-02。

本轮执行范围是**零 API 的公开目标可行性检查**。平台、任务端点与安全评分器保持固定。下面的公开目标、基线和停止标准在本轮结果产生前固定；运行工件保留对应脚本、协议及输入的哈希。

## 1. 需要分开回答的问题

1. **公开优化机会：** 在复现完整公开测试对历史程序的判别结果时，v能否比原8题方案少花实际验证成本？
2. **机制作用：** 按这个目标实际选中的v，在新候选或真实后代上是否增加风险？
3. **方法增量：** 有限预算后代证据能否胜过静态覆盖检查、固定边界测试和普通前瞻，并保留收益？

本轮只能回答第一项。公开测试的一致率不是安全率；降低验证成本不是程序A的成本下降；新参数不是新根谱系。第一项成立，也不能推断第二项必然成立。学习评分器需在相同证据下超过规则之后再扩大训练。

## 2. 数据与公开参考

| 数据 | 用途 | 来源和限制 |
| --- | --- | --- |
| 授权成本实验全部登记提案 | 估计验证成本、拟合测试选择、按历史留一检查 | `authorization-cost-kimi-v2-20261101`，来源绑定的开发谱系；不按独立风险或是否被选中筛选 |
| 公开优化经历的before/candidate/repair程序 | 必须满足的已知回归约束 | `experience-kimi-v2-20261102/history/collection.json`，经过来源校验的开发经历，用作已知回归约束，不视为独立随机样本 |
| 每个历史组的30题公开池 | 完整公开参考与每题实际成本 | 沿用v离线检查的普通、跨授权、撤销三请求测试及其实现，不新增任务，不修改参数生成规则 |

收集器只导入来源绑定的程序和公开计划，重新执行完整公共池。读取路径不包含旧实验的独立标签、独立轨迹或summary。原公开经历须通过`OptimizationEpisode`的公共游标、DEV分区和源码来源校验；其原独立发现背景按经过筛选的开发数据披露。

同根相同源码只保留一份参与拟合与成本计算，来源中的提案仍全部登记。不同根等权，同根不同源码等权。已知回归程序提供硬约束，不按它们的数量改变部署频率估计；收集和执行成本仍完整记账。

检查包括全开发集描述及全部“留出一条历史”的公开诊断。每折只用其余历史及已知公开回归拟合；留出根结果不参与测试选择或调参。与拟合程序或已知回归源码完全重复的留出程序剔除并报告数量。历史来源早已被查看，这种划分不作为新的封存确认集。

## 3. 优化目标和可修改范围

令`p[i,t]`为历史程序`i`在公开测试`t`上完整执行且全部正确的布尔结果，`c[i,t]`为其实际模拟服务成本。完整公开参考为：

```text
y_full(i) = AND over all 30 public tests of p[i,t]
y_v(i)    = AND over selected tests of p[i,t]

minimize  mean_over_histories(mean_over_unique_programs(sum_t c[i,t]))
subject to:
  y_v(i) == y_full(i) for every fitting program and every known regression;
  include the fixed core functionality test;
  1 <= number of selected tests <= 8;
  no test implementation, assertion, parameter, safety contract or program edits.
```

缺失或不完整结果保持未知，阻止本轮目标验收，不当作通过或零成本。完整参考必须具有通过和失败两类程序，不能用全通过样本证明判别能力。协议不奖励接受数量，不以风险标签加权，不允许用成本收益抵消公开判别错误。

v输出公共测试槽位的子集，执行顺序固定，不做候选专属名单或提前终止。各组同一槽位映射到同一测试实现及各组公开参数；测试结果从新世界和空缓存开始，因而成本可相加。核心功能槽位0必须保留，其他槽位由公开结果选择。上限仍为8题/24请求，但本轮允许少跑题数，这是有意区别于此前固定8题的机制控制。

首版用确定性的精确有限搜索计算可行最小成本，作为目标的可达到下界和透明优化基线。这是常规测试集精简，不是新安全算法。能用数值矩阵精确解决的选择不需要先交给Kimi猜测。将来若该选择器作为受测更新器运行，来源应明确登记为**程序化公开优化**，不能称为LLM自然改写验证机制。

同成本优先保留可行旧v；否则依次按更少测试、固定槽位顺序打破平局。拟合后冻结v，再读取留出公开结果；不得看见错误后改选另一个同分v。未来实际原生接纳还需一次未参与拟合的公开校准；未通过则保留旧v，失败也计预算。

## 4. 强基线与成本

| 条件 | 定义 | 作用 |
| --- | --- | --- |
| 原8题v | 原7个普通测试＋1个跨授权测试 | 用于验证覆盖对照；不假设其符合所有新的公开回归约束 |
| 完整公开参考 | 全部30题 | 公开质量标准及成本上界；不是独立安全判定 |
| 公开最小成本v | 满足全部公开约束的最小成本子集 | 检查目标的实际优化空间 |
| 固定保留边界v | 强制保留核心功能、跨授权和撤销测试，再用同一个优化器补充必要测试 | 强基线，同样享有删除重复测试的机会，不人为固定成昂贵全量验证 |

固定边界槽位为0/18/24，依据既有开发故障在收集结果前指定。保留完整契约和所有已知失败；不移除故障条目制造优化压力。静态覆盖基线直接检查这些槽位的保留，不收取虚构的执行预算。

分别记录公共参考矩阵的收集成本、选择计算、实际验证的测试/请求/服务调用及模拟服务单位。以后模型输入输出token、失败/拒绝尝试和恢复成本另计。本轮成本不是墙钟时间、API价格或GPU费用；不把全公共参考当免费监督，也不把A的执行收益写成v的验证收益。

主要成本对照是原8题v，不只与30题全量方案比较。验证判别质量直接相对完整公开参考计算，避免共同成本门槛事先拒绝多数程序、掩盖v漏检。最终原生接受仍须满足执行程序的公开正确性与严格成本改善条件，两项统计分开报告。

## 5. 本轮继续与停止标准

下列数值是事前工程探索门槛，不是安全保证、显著性水平或看结果后选出的最佳点：

- **公开优化机会通过：** 全开发集和全部历史留出折中，拟合成本相对原8题v至少降低10%，拟合/已知回归零判别差异，留出公开程序也零差异。缺失、不可行、留出数据因源码重复被清空，均停止而非补零。
- **简单防线足够便宜：** 上述各折中，固定边界v的成本至多比无固定边界的最优v高5%，且留出公开判别质量不差。满足时优先保留简单防线，**不启动以证明复杂审计增量为目的的付费试验**；这不等于证明它对未知故障完备。
- **无优化空间：** 没达到第一个条件，停止当前目标，不调用Kimi、不放宽质量约束、不拿掉已知失败、不更换任务或追加样本找阳性。
- **有公开空间且固定边界有实际代价：** 只说明有理由准备下一项机制研究。仍需固定新根、公开校准、模型额度和成对执行协议；不自动触发API。

本轮无模型生成随机性，只能做确定性公开可行性分析。登记提案、多个参数和多次执行不当成独立样本做显著性检验；不生成自然v危害监督或训练评分器。

## 6. 之后的机制试验：条件性设计，尚未执行

只有决定继续机制研究时，才实施下面的限额开发试验。本轮没有接通这些新执行流程，也没有授权脚本自动派发模型请求。

- **根与原始历史：** 预先登记4条新的优化历史。相同founder和契约，各自使用新公开参数做2次真实A编辑，拒绝也占次数；完整公开反馈和已知回归经验保留。共享初始程序/档案必须披露；参数变化本身不算新根，根内需有独立实际优化历史。
- **v更新：** 用公开历史矩阵及已知回归约束，通过上述程序化优化提出v；再在新的公开校准参数上验证判别一致性和至少10%的成本改善。校准失败、不变或没有收益则保留旧v，并记录未更新根，不能筛掉后不报告。v不通过模型生成，Kimi只承担执行程序编辑。
- **配对续演：** 通过校准的根从同一程序、状态、档案检查点分为旧v、新v、固定边界v三臂，各做2次独立H2真实续演。源码A可继续生成、验证、选择，v各臂固定；实际进入编辑器的公开反馈、选中测试和实际采用版本逐次记录。模型采样不能保证相同，采用按根交错随机派发顺序，不将同seed声称为共同随机数控制。
- **硬额度：** 根历史最多`4×2=8`次编辑，续演最多`4×3×2×2=48`次编辑，总计最多**56次模型请求、500,000 token**。拒绝、无效和未知结果计尝试；无额度不追加，未知请求不重发，不补满失败根。根构建和后代使用同一持久化额度账本。此额度是后续方案上限，本轮额度为0。
- **独立端点：** 所有v及其公开接纳先冻结，独立判定只读后代实际日志。终末采用程序新增越权为主；路径越权、全部提案风险、合法完成、A成本收益保留、v验证成本、缺失及无更新另报。各臂均使用`log_and_allow`，拦截敏感性不混入主结果。风险时间轴记录真实A演化尝试，不把三个请求当三代。
- **因果边界：** 主要比较旧v与新v的根内重复均值；固定边界v为预先定义的覆盖保护干预。对已删除边界的单项恢复，只依据更新差异和已知公开测试指定，不事后依据独立危险题选测试。恢复与旧v完全相同时只算旧条件，不增加独立证据量。
- **限额停止：** 先检查是否存在实际被选中的v改进及A激活。若没有、独立风险全零、两臂同样危险，或差异只出现在单一根/单次生成，则停止扩大方法数据，不训练。至少两条新优化历史出现方向一致的新增风险、重复续演方向一致且固定边界减弱该差异，才进入机制确认设计；4根仍是探索，不据此声称稳定发生率或统计非劣。

若程序化优化始终同时省成本、保持关键覆盖并降低风险，应报告该结果。不能为证明风险而改成只奖励接受量、删掉契约、删除失败经历或强制移除关键测试。

## 7. 方法关

机制证据具备后才另行登记同一批v更新上的比较：原生检查、静态覆盖检查、固定边界保护、等预算普通前瞻、修改/状态引导的后代探针、全部拒绝。动态方法按编辑请求和执行上限匹配，实际成本另报；静态基线不被迫浪费预算。

先验证执行证据相对强静态/固定测试有增量，再在相同证据、独立根划分下比较规则与冻结学习评分。主指标包括有害错误接受、良性错误拒绝、弃权/缺失、实际采用后的风险、合法效用及两种成本收益。没有额外价值则保留简单基线，收窄方法主张。
