# 实现范围

当前定位、最近验证和待办统一维护在 [HANDOFF](HANDOFF.md)。架构接口见 [architecture](architecture.md)，运行入口见 [README](../README.md)。本页只区分能力范围，不另存一份阶段状态。

| 范围 | 当前支持 |
| --- | --- |
| 通用平台入口 | 系统/任务/检测器/协议/后端配置，能力与工具兼容性预检 |
| 系统适配 | 确定性 fixture、bounded Task A、真实受限源码 q 优化参考系统、固定官方版本的 GEPA |
| 执行与证据 | 有限工具真实修改模拟状态；独立效果 oracle；稳定调用身份和恢复 |
| 配对续演 | 同一公共执行实现用于隔离的旧/新分支、短探针和长程标签 |
| 重复机制干预 | `q-effect` 复用公共内核；旧/新/完整上下文恢复/不变采样对照，固定任务、独立重复、新公开参数复验及按根统计；仅开发实验 |
| 优化经历档案与诊断 | `experience` 记录真实公开修改、检查和修复，先验证历史可用再比较相关/无关/sham与两种反馈条件；匹配序列化字节而非tokens，共享历史的参数block不当独立根；效果结论见HANDOFF |
| 已优化检查点上的q诊断 | `optimized-q` 公开选取并复验检查点，复用公共内核进行固定q的H2编辑/验证/选择；全局36调用和500k token预算、轨迹级检验、未知不重试；不是自然q优化或恢复确认 |
| 公开 q 选择与定向恢复 | 公共候选编辑/验证/激活搜索、平分保留旧q和未知结果弃权；单个选中槽的相关/无关替换及新q采样对照；接口已控制验收，不代表完整自然q实验已成立 |
| 有效性试验 | 旧/新 × 冻结/原生演化四组；可选四种审计基线先决定后独立评价；按 root 汇总并分层，保留缺失与弃权 |
| 更新准入 | 检测报告与策略分离；身份核对和受控激活；拒绝不继承候选 |
| 学习 | 离线长程监督、分区检查、训练/校准、冻结预测；授权成本 q 实验导出独立标签，支持静态/短探针/组合 CPU 基线与盲评价 |
| 模型 | editor/actor 独立网关；显式私有凭据加载；真实Kimi q/源码后代/学习盲评价已跑通；自然有害q识别与方法增量尚未验证 |
| 任务 | 确认授权工作流、公共内核上的授权程序成本任务；报表/金融探索脚本保留，暂不扩展；各轮真实结果见HANDOFF，控制轨迹不充当自然证据 |
| 防御实验 | 一次根更新准入后的固定部署比较；连续每轮外部准入未完成 |
| 不可信代码 | 授权成本实验支持有资源上限的Python形状AST解释器；未提供任意生成 Python/shell 的操作系统隔离 |

旧 M1–M4 的 P0、旧 Task A 数据格式与命令保留兼容；[原冻结验收映射](acceptance_map.md) 只解释原规格，不替代新平台验收。旧运行绑定其源码与协议，不自动迁移。
